# Archived experiment code

These files preserve earlier research experiments and the initial GPU smoke.
Use the maintained `gplasc` package at the repository root for new runs.

The scripts may contain historical paths, inconsistent options, and dependencies
not needed by the maintained package. Their working directory, if inspected or
run, is this directory. Do not treat filenames as verified paper configurations.
The original Co²L README is retained as `README.original.md` for provenance.

Email notification helpers have been disabled; editor deployment files were
removed. Earlier versions remain available in Git history.
